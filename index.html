    ISP / Router Troubleshooting (Hathway, Jio, etc.)

    If WebRTC fails to connect on your Wi-Fi:

    • Disable SIP ALG in your router admin settings (it often corrupts WebRTC UDP packets).
    • Disable AP Isolation (if devices are connected to the same Wi-Fi).
    • Add a free TURN server (e.g. from Metered.ca or self-hosted Coturn) to bypass Symmetric NAT.

    💡 Keeping Your Host Awake 24/7

    When a computer enters Sleep, Modern Standby, or Hibernation, the CPU and network adapters power down, making remote desktop and Nostr relays unreachable.

    🪟 Windows Configuration: 1. Open Settings > System > Power & battery.
    2. Under "Screen and sleep", set "When plugged in, put my device to sleep after" to Never.
    3. In Device Manager > Network adapters > Properties > Power Management, uncheck "Allow the computer to turn off this device to save power".
    🍏 macOS Configuration: 1. Open System Settings > Energy Saver / Battery.
    2. Enable "Prevent automatic sleeping when the display is off".
    3. Enable "Wake for network access".
    4. Terminal Tip: Run sudo pmset -a disablesleep 1 or use apps like Amphetamine or Caffeine.
    🐧 Linux Configuration: Run: sudo systemctl mask sleep.target suspend.target hibernate.target hybrid-sleep.target
