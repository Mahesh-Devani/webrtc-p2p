⚡ How to run Host Bridge (Zero Dependencies)

The Host Bridge injects native mouse clicks and keyboard typing into your OS. Requires standard Python 3 only (no pip install required).

Option 1: One-line Terminal Command (macOS / Linux)
curl -sSL https://raw.githubusercontent.com/mahesh-devani/webrtc-p2p/main/remote-desktop-host/bridge.py -o bridge.py && python3 bridge.py
Option 2: Windows PowerShell
Invoke-WebRequest -Uri "https://raw.githubusercontent.com/mahesh-devani/webrtc-p2p/main/remote-desktop-host/bridge.py" -OutFile "bridge.py"; python bridge.py
Option 3: Download & Run Directly
  1. Click Download bridge.py or Download Folder (.zip) above.
  2. Open Terminal in that folder and run: python3 bridge.py
  3. macOS: Allow Accessibility in System Settings > Privacy & Security when prompted.
Option 4: Run as Persistent Background Service (Auto-Start)
Starts automatically on login so this PC is always reachable without keeping a terminal open:
• macOS: ./remote-desktop-host/install-service.sh
• Linux: ./remote-desktop-host/install-linux-service.sh
• Windows: run remote-desktop-host\install-windows-service.bat
🛑 Session Control: Use the "Disconnect" or "Stop Capture" button on the host dashboard to terminate control sessions immediately.

⚙️ Run as a Persistent Background Service

24/7 Unattended Access

Like Chrome Remote Desktop or TeamViewer, you can install P2P Connect as an automatic system background service. It starts on boot/login, runs silently without keeping an open terminal, and automatically recovers if closed.

⚠️ Browser Tab Requirement: Keeping host.html Open is Required
The host.html browser tab must remain running for Remote Desktop to work. It holds your active WebRTC 60 FPS video capture stream and listens for encrypted Nostr connection signals. You can minimize or hide Chrome, but do not close this tab/window. The automated background service launcher (start-host.sh) automatically opens and keeps Chrome running for this reason.
📦 Download Complete Host Folder (.zip):
Includes all scripts, bridge.py, macOS LaunchAgent, Linux systemd, and Windows Task Scheduler installers in a single zip archive.
Download remote-desktop-host.zip
1. Install & Start Service Registers a user LaunchAgent (~/Library/LaunchAgents/com.p2pconnect.host.plist) that auto-starts on login:
cd remote-desktop-host && ./install-service.sh
2. Service Management Commands
Check Status launchctl list | grep com.p2pconnect.host
View Live Logs tail -f /tmp/p2pconnect-host.log
Uninstall / Stop ./remote-desktop-host/uninstall-service.sh
💡 macOS Permissions: On first run, grant Accessibility and Screen Recording to Terminal / Python in System Settings > Privacy & Security.
1. Install & Start Service (systemd User Unit) Creates ~/.config/systemd/user/p2pconnect-host.service and enables lingering:
cd remote-desktop-host && ./install-linux-service.sh
2. systemd Management Commands
Check Status systemctl --user status p2pconnect-host
View Live Journal Logs journalctl --user -u p2pconnect-host -f
Stop Service systemctl --user stop p2pconnect-host
Uninstall Service ./remote-desktop-host/uninstall-service.sh
💡 Headless / Remote Login: The installer runs loginctl enable-linger $USER so the service runs in the background even before graphical desktop login.
1. Install via Batch Script (Fastest) Registers a Windows Scheduled Task using pythonw.exe (runs completely silently with NO command prompt window):
  1. Navigate to the remote-desktop-host directory.
  2. Right-click install-windows-service.bat and select Run as administrator.
  3. The bridge will start immediately and automatically run whenever you log in.
2. Manual Setup (Command Prompt / PowerShell)
schtasks /Create /TN "P2PConnectHost" /TR "pythonw.exe bridge.py" /SC ONLOGON /RL HIGHEST /F
3. Manage or Uninstall
Check in Task Scheduler Press Win+R, type taskschd.msc, locate P2PConnectHost.
Uninstall / Stop schtasks /Delete /TN "P2PConnectHost" /F
